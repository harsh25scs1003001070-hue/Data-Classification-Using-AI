# 🤖 Data Classification Using AI

## Project 2

A basic supervised machine learning classification project using
the Iris dataset and a Decision Tree algorithm.

---

## 🎯 Goal

Build a basic classification model using a small dataset.

The project demonstrates:

- Loading a dataset
- Understanding data
- Splitting data into training and testing sets
- Training a classification algorithm
- Making predictions
- Evaluating the model
- Visualizing the decision tree

---

## 🧠 Machine Learning Algorithm

Decision Tree Classifier

The model learns patterns from labeled training data and uses those
patterns to classify new observations.

---

## 📊 Dataset

The project uses the Iris dataset.

### Features

1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

### Classes

- Setosa
- Versicolor
- Virginica
